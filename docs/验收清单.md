# 验收清单

每一项都应由执行人记录日期和结果。未通过的项目不能用“页面能打开”替代。

## 代码检查

- [ ] `npm ci` 可从锁文件完成干净安装。
- [ ] `npm ci --prefix cloudfunctions/survey` 可安装云函数依赖。
- [ ] `npm run test` 全部通过。
- [ ] `npm run build` 成功，控制台无构建错误。
- [ ] Pull Request 的 `Verify pull request` 工作流通过。

## UI 验收

- [ ] 375 × 812、390 × 844、430 × 932 三个视口与旧 H5 最终效果一致。
- [ ] 所有题目未完成时提交按钮不可提交。
- [ ] 选项、原因、弹窗、加载动画和成功页状态正确。
- [ ] 没有恢复 H5 不需要的原生导航栏。

## 接口验收

- [ ] `GET` 健康检查返回 `status: ok`。
- [ ] 正常提交返回 201 和 `submissionId`。
- [ ] 同一个 `requestId` 重复提交不会生成第二条记录。
- [ ] 缺题、非法原因和错误请求格式返回 400。
- [ ] 非允许来源没有 `Access-Control-Allow-Origin` 响应头。
- [ ] CloudBase PostgreSQL 的 `survey_submissions` 表能查到对应行。

## 发布验收

- [ ] GitHub `production` Environment 已配置审批人。
- [ ] CloudBase API Key 与环境 ID 只放在 GitHub Secrets。
- [ ] Pages 的函数 URL 只放在 GitHub Variable。
- [ ] 后端流水线成功后执行健康检查。
- [ ] Pages 发布后完成一次真实提交和数据库回查。
- [ ] CloudBase 日志中无持续 5xx，且没有输出完整答卷或密钥。

## 正式上线门槛

- [ ] 接入真实登录和服务资格校验。
- [ ] 增加限流、防刷和审计。
- [ ] 明确隐私政策、数据保留和删除机制。
- [ ] 正式权益由业务后端发放，不能使用 `reward.mode=demo`。
