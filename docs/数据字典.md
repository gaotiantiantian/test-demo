# 数据字典

本文定义问卷前端、云函数和云数据库之间的数据契约。修改字段时，应同时更新类型、服务端校验、测试和本文。

## 提交请求

| 字段 | 类型 | 必填 | 说明 | 示例 |
| --- | --- | --- | --- | --- |
| `requestId` | UUID 字符串 | 是 | 单次提交唯一标识，用于避免重复写入 | `018f8f8e-7d30-7c22-9d60-3d0bdc531111` |
| `visitorId` | UUID 字符串 | 是 | 无登录演示版的浏览器访客标识 | `018f8f8e-7d30-7c22-9d60-3d0bdc532222` |
| `serviceId` | 字符串，最多 64 字符 | 是 | 当前问卷对应的演示服务 | `demo-service` |
| `answers` | 数组 | 是 | 固定包含 `q1`、`q2`、`q3` 三题 | — |
| `answers[].questionId` | 字符串 | 是 | 题目 ID | `q1` |
| `answers[].value` | `positive` 或 `negative` | 是 | 主选项 | `positive` |
| `answers[].reasonIds` | 整数数组 | 是 | 负向原因索引；正向答案应为空数组 | `[0, 1]` |

## PostgreSQL 数据表

表名：`public.survey_submissions`。迁移脚本位于 [`database/migrations`](../database/migrations)，必须按编号执行。浏览器不直接读写该表；当前不向普通数据库角色授予权限，由云函数通过服务端身份访问。

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| `request_id` | `uuid` | 等于请求中的 `requestId`，也是主键和幂等键 |
| `visitor_id` | `uuid` | 无登录演示版访客标识；正式项目应替换为账号用户 ID |
| `service_id` | `varchar(64)` | 服务标识 |
| `answers` | `jsonb` | 服务端按白名单校验并补全题目文案后的答卷 |
| `reward` | `jsonb` | 演示权益结果、是否发放以及下次可获奖时间 |
| `reward_granted` | `boolean` | 本次提交是否实际获得奖励 |
| `submission_mode` | `varchar(16)` | 当前固定为 `demo` |
| `submitted_at` | `timestamptz` | 数据库写入时间，统一保存时区信息 |

## 公开响应

云函数只返回 `submissionId`、`requestId`、`submittedAt`、`answers` 和 `reward`。数据库内部字段不应未经审查直接透传。

## 数据边界

- 当前只收集问卷选择，不收集姓名、手机号、证件、交易账户等敏感信息。
- 演示环境的数据应设置保留期限并定期清理，建议不超过 30 天。
- 正式业务接入前，必须补充用户授权、隐私政策、身份鉴权、数据删除流程和真实权益发放审计。
