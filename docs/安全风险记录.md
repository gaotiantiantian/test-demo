# 安全风险记录

## SR-001：CloudBase SDK 间接依赖漏洞

| 项目 | 内容 |
| --- | --- |
| 发现方式 | `npm audit --omit=dev` |
| 当前直接依赖 | `@cloudbase/node-sdk@3.18.7` |
| 风险来源 | SDK 间接依赖的旧版 `axios`、`lodash.set`、`lodash.unset` |
| 当前状态 | 官方最新 SDK 仍包含相关依赖，暂无不破坏兼容性的自动修复 |
| 适用范围 | 仅教学演示环境，不允许承载真实客户敏感数据 |

### 当前缓解措施

- 请求字段经过白名单校验，用户不能控制 SDK 请求的目标 URL。
- 请求体限制为 16 KiB。
- 不把完整答卷和异常对象写入日志。
- 数据库只由云函数访问，浏览器不持有数据库凭证。
- API Key 仅保存在 GitHub Environment Secret。

### 后续处理

每次升级 CloudBase SDK 前重新执行审计和回归测试。腾讯官方依赖链修复后，单独创建依赖升级 PR；不要执行 `npm audit fix --force` 自动降级或跨主版本替换 SDK。

正式上线前，这项风险必须由开发负责人重新评估并关闭或接受。
